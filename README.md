# توثيق الأعطال — Ops11141/mn

واجهة عربية RTL أولية لمشروع توثيق الأعطال لقسم الصيانة بالشركة السعودية للطاقة.

## الموجود في النسخة الحالية
- لوحة مؤشرات لإجمالي الأعطال وقيد المعالجة والأعطال التي تم إصلاحها.
- نموذج لتسجيل العطل والمعدة والمغذي والموقع والتاريخ والوصف واسم المبلّغ.
- صور اختيارية قبل الإصلاح وبعده.
- البحث والتصفية حسب الحالة.
- تغيير الحالة وتصدير السجل بصيغة CSV.
- تصميم متجاوب بألوان كحلية وزرقاء وسماوية.

## تنبيه أمني مهم
هذه نسخة واجهة تجريبية فقط. البيانات تحفظ محليًا في المتصفح (localStorage) ولا تتزامن بين الموظفين أو الأجهزة. لا توجد حتى الآن مصادقة حقيقية أو صلاحيات آمنة. لا يمكن الاعتماد على إخفاء الأزرار في الواجهة كوسيلة لحماية البيانات.

## قبل الاستخدام التشغيلي
1. ربط المشروع بخدمة خلفية وقاعدة بيانات مركزية.
2. تفعيل تسجيل الدخول والتحقق من الهوية.
3. فرض الصلاحيات على الخادم: المشرفون المصرح لهم فقط ينشئون/يعدلون/يحذفون، والموظفون يتصفحون ويبحثون فقط.
4. تخزين الصور في مساحة تخزين محمية، والتحقق من نوع الملف وحجمه.
5. اختبار الصلاحيات والنسخ الاحتياطي وسجل التعديلات قبل النشر التشغيلي.

## تشغيل الواجهة
افتح index.html في متصفح حديث. هذه الخطوة للمعاينة فقط وليست نشرًا تشغيليًا آمنًا.
